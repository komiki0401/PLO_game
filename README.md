# DOUBLE BOARD PLO5

プレイチップ専用、5カード PLO・ダブルボード・ボムポット。React + TypeScript + Vite。1人対CPU、2〜6人卓に対応します。換金・入出金・賞金はありません。

## 開発

Node.js 24 / npm 11 を推奨。

```sh
npm ci
npm run dev
```

```sh
npm test                 # 役・ポット・ベッティング・1,000ハンドの不変条件
npm run build            # TypeScript + 本番ビルド
npx playwright install --with-deps chromium
npm run test:e2e         # PC / モバイル、2ハンド連続操作・設定・履歴
```

既存の /workspace/PLO_game チェックアウトを使います。クラウドの各タスクは隔離済みなので、新規 worktree は不要です。開発サーバーのプロセスは新しい環境で再起動してください。秘密鍵、APIキー、DB、外部サービスは不要です。

## ルール

- 同一52枚デッキ、ホール5枚、ボード2組。アンティ後にフロップ2組を公開し、プリフロップのベットはありません。バーンカードは使用しません。
- 各ボードの役は必ずホール2枚＋そのボード3枚。ハイのみ。A2345は5ハイのストレート。
- 最低ベット＝アンティ。レイズ上限は現在の最高ベット＋現在のポット＋コール額（そのストリートの合計ベット額として入力）。スタックを上限とします。
- 最低レイズ幅は直前のフルベット／レイズ幅。ショートオールインは幅を更新しません。前回のアクション以後に直面する増額がフルレイズ幅に達すればレイズ権を再開します。
- チェック可能時はFoldを表示しません。コール不能な端数スタックはショートコールのオールイン。対戦相手全員がオールインの場合、未コール額へのコール／フォールドだけ行い、自動ランアウトします。
- 未コール分を返却し、累積拠出額でメイン／サイドポットを作成。フォールドの拠出分も含め、各ポットの有資格者だけを比較。
- 各ポットの奇数1チップはBOARD Aへ。同点で割り切れないチップはボタン左から時計回りに1枚ずつ。チップは整数。
- スタック0の席は次のハンドから休止。2人未満になったら新しいセッションを開始できます。プレイヤー破産時は観戦可能です。

## 構成

- `src/game/cards.ts`: デッキ・カード・組み合わせ
- `src/game/evaluate.ts`: 5枚役判定とOmaha全候補比較、使用カードを返却
- `src/game/pots.ts`: メイン／サイドポットとボード別分配
- `src/game/betting.ts`: 合法アクション、ポットリミット、レイズ権
- `src/game/engine.ts`: 状態遷移。`act(state, action)` は新しい状態を返す
- `src/game/cpu.ts`: 公開情報だけを使うヒューリスティックCPU
- `src/App.tsx`: React画面・タイマー・音・履歴・統計

EASYは緩い参加判断、NORMAL/HARDはランアウトのMonte Carlo推定とポットオッズを使用します。難易度で試行数・ブラフ頻度を変えます。HARDは現在の両ボードのナッツをブロッカー込みで調べ、マルチウェイのスクープ率も考慮します。GTOソルバーではありません。

履歴は直近30ハンドをメモリ保存（一覧は直近8件）。「リプレイ」はスライダーで各アクション時点の状態を再表示します。伏せ札は当時の公開状態を維持し、終了時にショーダウンを確認できます。統計と設定はlocalStorageに保存されます。

オンライン拡張時はゲームモジュールをサーバー側で実行し、合法性を権威的に検証してください。伏せ札を含むState全体はクライアントに配信せず、各席用の公開ビューを生成する設計を想定しています。現在はローカルCPU戦専用です。シャッフルはプレイチップ用のMath.randomベースです。

## GitHub Pages

`.github/workflows/pages.yml` がmainへのpush時にユニットテスト・ビルド・ブラウザテストを実行し、すべて通った場合だけデプロイします。PRでは検証のみ実行します。Viteの相対baseによりリポジトリ配下で動作します。

初回のみGitHubリポジトリの **Settings → Pages → Build and deployment → Source → GitHub Actions** を選択してください。mainへpushし、Actionsの「Test and deploy to GitHub Pages」が成功すると公開されます。標準の公開先は `https://komiki0401.github.io/PLO_game/` です。URLの利用可能性はデプロイ完了後に確認してください。
